## What it does

<CardGrid>
	<Card title="Panels, not commands">
		Status, Files and Log down the left, a Main detail view beside them and the svn Command Log
		beneath. Switch with the number keys or <kbd>tab</kbd>. [The panels](/guides/panels/)
	</Card>
	<Card title="Staging that SVN understands">
		<kbd>space</kbd> stages a file or a whole directory subtree into a changelist — a git-index-like
		workflow, built out of plain `svn changelist`. [Staging & commit](/workflows/staging-and-commit/)
	</Card>
	<Card title="Named changelists">
		Group the staged set into named lists, drill into any of them in a tabbed view, and commit one as
		a unit. [Changelists](/workflows/changelists/)
	</Card>
	<Card title="Diffs you can work in">
		Additions, deletions and hunk headers each tinted. Search in place, read it side by side with
		<kbd>s</kbd>, or write it to a file with <kbd>w</kbd>. [Working with diffs](/workflows/diffs/)
	</Card>
	<Card title="Filter anything">
		<kbd>/</kbd> filters the focused panel, with `rev:`, `user:`, `state:` and `cl:` parameters for
		the ones that support them. [Filtering & searching](/workflows/filtering-and-searching/)
	</Card>
	<Card title="Update without surprises">
		Update to HEAD or to any revision picked out of the Log panel. Conflicts are spelled out before
		you confirm. [Updating the working copy](/workflows/updating/)
	</Card>
	<Card title="Resolve it side by side">
		<kbd>m</kbd> lays a conflict — or a hunk a patch could not place — out two panes wide, with a key
		to take either side, both, or your editor. [Resolving conflicts](/workflows/conflicts/)
	</Card>
	<Card title="Open it in your editor">
		Hand the selected file to vim, nvim, nano, or VS Code — which opens the real file in the window
		you are already in. [Opening files in an editor](/workflows/editor/)
	</Card>
	<Card title="Themes and settings, in app">
		Six colour schemes and an in-app settings editor, written back to your config file.
		[Themes](/reference/themes/) · [Configuration](/reference/configuration/)
	</Card>
</CardGrid>
