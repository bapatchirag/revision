## Inside prompts and overlays

Modal contexts, which the menu above does not cover.

| Context | Keys |
|---|---|
| Commit editor, settings form | <KeyCap key="ctrl+s" /> submits, <KeyCap key="esc" /> cancels |
| Changelist-name prompt | <KeyCap key="tab" /> toggles between typing a new name and picking an existing changelist |
| Confirmation dialog | <KeyCap key="enter" /> or <KeyCap key="y" /> confirms, <KeyCap key="esc" /> or <KeyCap key="n" /> cancels |
| Side-by-side overlay | <KeyCap key="[" /> / <KeyCap key="]" /> turn between files, <KeyCap key="e" /> opens the file on the open page in your editor, <KeyCap key="s" /> or <KeyCap key="esc" /> closes |
| Filter input | <KeyCap key="enter" /> keeps the query, <KeyCap key="esc" /> clears it |
| Main / Status with an active search | <KeyCap key="n" /> / <KeyCap key="N" /> walk to the next / previous [match](/workflows/filtering-and-searching/#main-and-status) |
