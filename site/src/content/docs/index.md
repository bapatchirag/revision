A lazygit-style terminal UI for Subversion (SVN). `revision` gives you a fast,
keyboard-driven interface over the `svn` command line — review changes, stage with
changelists, commit, update, and browse history without leaving your terminal.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/bapatchirag/revision/main/install.sh | sh
```

You need the [`svn` client](/guides/requirements/) on your `PATH`. See
[Installation](/guides/installation/) for the other methods.
